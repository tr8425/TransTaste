# TransTaste 프로젝트 리뷰

## 프로젝트 개요

**TransTaste**는 해외 식당 메뉴판을 스캔해서 번역, 알레르기 정보, 재미있는 음식 정보를 제공하는 **여행자용 메뉴 번역 앱**입니다. Next.js(App Router) + TypeScript 기반의 모바일 우선(PWA) 웹앱으로 구성되어 있습니다.

---

## 잘 된 점

**디자인 & UI/UX**
- 따뜻한 오렌지 계열(`#D85A30`) 컬러 팔레트가 음식 앱의 분위기와 잘 맞고, 전체적인 톤앤매너가 일관성 있습니다.
- 모바일 컨테이너(`mobile-container`) 방식으로 데스크탑에서도 모바일 앱처럼 보여주는 레이아웃이 잘 처리되어 있습니다.
- 카메라 촬영 → 결과 화면의 흐름이 직관적이고, 하단 내비게이션(Home / Camera / History) 구성도 심플하게 잘 되어 있습니다.
- Results 페이지에서 음식 카테고리 필터 탭(All / Main / Soup / Noodle / Rice / Side / Drink / Dessert)이 잘 구현되어 있습니다.

**기능**
- 메뉴 스캔 방식이 **카메라 / 갤러리 / URL / 텍스트 직접 입력** 등 4가지로 다양하게 지원되는 점이 좋습니다.
- 각 음식에 재료(Ingredients)와 알레르기 정보(Allergens & Dietary)가 뱃지 형태로 표시되어 빠르게 확인 가능합니다.
- 카메라 접근 불가 시 "Choose from Gallery" 폴백(fallback) 처리가 부드럽게 되어 있습니다.
- PWA 설정(`manifest.json`, `apple-mobile-web-app-capable`)이 되어 있어 홈 화면 추가 지원이 가능합니다.

**수익화 모델**
- 상세 정보(맛 프로필 레이더 차트, Fun Facts 등)는 "Unlock flavors, facts & more — $2.99" 페이월로 잠궈두는 구조가 명확합니다.
- 7일 Trip Pass 방식의 일회성 결제 모델은 여행자 타겟에 잘 맞습니다.

## 개선이 필요한 부분

**버그 / 미완성 기능**

하단 내비게이션의 **History 탭이 `/history` 라우트로 연결되어 있는데, 해당 페이지가 404**입니다. History 페이지가 아직 구현되지 않았거나, 라우트 경로가 잘못 설정된 것으로 보입니다.

Recent Scans 섹션의 항목들이 모두 `/results`로 연결되어 있어, 실제로 각각의 이전 스캔 내역을 불러오는 기능은 아직 미구현 상태입니다.

**홈 화면의 스캔 카운터**인 "7 left" 표시가 상단에 있는데, 몇 번 남았는지를 의미하는 것 같지만 맥락 없이 표시되어 사용자가 무슨 의미인지 바로 이해하기 어렵습니다. "7 free scans left" 처럼 더 명확하게 표시하거나, 툴팁/인포 아이콘을 추가하는 것을 추천합니다.

**UX**

메뉴 결과 상세(Detail Sheet)가 전체 화면으로 뜨지 않고 하단에서 올라오는 모달 방식인데, 스크롤 영역이 뒤쪽 리스트와 겹쳐 있어 스크롤 이벤트가 충돌할 수 있습니다. 상세 페이지는 별도 라우트(`/results/[id]`)로 분리하는 것이 더 자연스러울 수 있습니다.

"Combo Recommendations" 버튼이 하단에 있지만 실제 기능이 동작하는지 확인되지 않았고, 결과 화면 하단에 고정되어 있어 메뉴 목록이 가려질 수 있습니다.

**기술적 구조**

현재 소스 구조를 보면 `/src/app/page.tsx`, `/src/app/results/page.tsx`, `/src/components/ui/BottomNav.tsx` 등이 확인되는데, 결과 데이터가 현재 하드코딩된 mock 데이터로 보입니다. API 연동 레이어(실제 AI 번역/인식 기능)가 구현되지 않은 것으로 추정됩니다.
