## 0. 이번 QA의 목적

v3 이후 대규모 업데이트:
- 수익 시스템 보강 (크레딧 차감, Stripe 연결, 소프트 페이월)
- 보안 (API 레이트 리밋)
- SEO 기반 (메타데이터, robots, sitemap, JSON-LD, 약관/방침)
- 콘텐츠 페이지 신규 (/foods, /guide, /terms, /privacy)
- 알레르기 4단계 UI, disclosure, Present Mode 개선
- 사용자 API 키 직접 입력 기능
- Free 10회로 변경

**API 호출 가능 횟수:** 잔여 1회 (v1~v2에서 2회 사용)
Mock 모드에서 대부분 검증 가능. API 키 입력 기능 검증 시 1회 사용 권장.

## 3. 알레르기 4단계 UI 검증 (신규)

### 3.1 DishRow 위험도 뱃지

- [ ] 결과(`/results`) → 요리 목록에서 알레르겐이 있는 요리 확인
- [ ] `allergen_risk` 값에 따른 뱃지 표시:
  - danger → 빨강 "ALLERGEN" 뱃지
  - warning → 주황 "CHECK" 뱃지
  - check → 노랑 "ASK STAFF" 뱃지
  - safe → 뱃지 없음
- [ ] 뱃지가 알레르겐 태그 앞에 표시

### 3.2 DishCard 행동 가이드

- [ ] 요리 탭 → 바텀시트 → "Allergens & Dietary" 섹션
- [ ] danger: 빨강 박스 "Contains your allergen. Consider an alternative dish."
- [ ] warning: 주황 박스 "May contain allergens. Ask staff if it can be prepared without."
- [ ] check: 노랑 박스 "Possible allergen presence. Ask staff to confirm ingredients."
- [ ] safe: 행동 가이드 박스 없음
