## 3. 전체 화면 구조 (v0.2)

```
온보딩 (최초 1회)
  ├─ 앱 소개 (무료 10회 안내)
  └─ 언어 + 알러지 설정

메인 탭바 (3탭)
  ├─ [홈]
  │    ├─ 입력 4종: 카메라 / 갤러리 / URL / 텍스트
  │    ├─ 크레딧 잔량 + Trip Pass 카드
  │    └─ 최근 스캔 히스토리
  │
  ├─ [히스토리]
  │    └─ 과거 스캔 목록 (오프라인 열람 가능)
  │
  └─ [프로필]
       ├─ 크레딧 / 패스 현황 + 구매
       ├─ 언어 설정 (출력 언어 / 메뉴 언어)
       └─ 알러지 프리셋 편집

스캔 플로우 (홈에서 진입)
  카메라 뷰 → 로딩 → 결과 리스트 → 음식 상세 카드
                                   └─ 조합 추천
                                   └─ Trip Pass 페이월

식당 대화 (결과 화면에서 접근)
  카테고리 선택 → 프리셋 카드 (현지어 + 발음 + 예측 답변)

팁 & 문화 (결과 화면에서 접근)
  국가 자동 감지 → 팁 정보 + 문화 칩 + 총액 계산기
```

## 4. 화면별 상세 설계 (v0.2)

### 4.0 온보딩 (신규)

**목적:** 최초 실행 1회 — 앱 소개 + 필수 설정

| 화면 | 요소 | 우선순위 |
|---|---|---|
| 온보딩 1 | 앱 소개 (번역 / 대화 / 팁 3가지 강조), 무료 10회 안내 | 필수 |
| 온보딩 2 | 출력 언어 선택, 알러지 프리셋 선택, 건너뛰기 가능 | 필수 |

알러지 프리셋은 저장 후 모든 스캔 결과에서 자동 강조. 프로필에서 언제든 수정 가능.

---

### 4.1 홈 화면 (v0.2 갱신)

**변경:** 카메라 버튼 하나 → 입력 4종 동등 배치

| 요소 | 내용 | 우선순위 |
|---|---|---|
| 입력 4종 버튼 | 카메라(메인) / 갤러리 / URL / 텍스트 | 필수 |
| 크레딧 잔량 | 항상 노출, 소진 전부터 인지 | 필수 |
| Trip Pass 카드 | 크레딧 옆에 상시 노출 | 필수 |
| 최근 히스토리 | 최근 3개 칩, 오프라인 열람 | 권장 |

URL 입력: SNS / 블로그 / 식당 홈페이지 메뉴 이미지 URL 붙여넣기.
텍스트 입력: 메뉴명만 알 때, OCR 실패 폴백 진입점.

---

### 4.2 카메라 화면 (v0.2 갱신)

| 요소 | 내용 | 우선순위 |
|---|---|---|
| 전체 화면 뷰파인더 | Google Lens 코너 가이드 오버레이 | 필수 |
| 언어 상태 바 | "자동 감지" 또는 현재 언어 + "변경" 버튼 | 필수 |
| 촬영 / 갤러리 / 플래시 | 하단 3버튼 | 필수 |

언어 변경은 카메라 뷰에서 바로 가능. 결과가 이상할 때 즉시 수정.

### 4.6 식당 대화 (신규)

**목적:** 언어 장벽을 물리적으로 해결 — 화면을 서버에게 보여주는 UX

| 요소 | 내용 | 우선순위 |
|---|---|---|
| 카테고리 탭 | 기본 요청 / 주문 / 계산 / 컴플레인 / 인사 | 필수 |
| 프리셋 카드 | 한국어 + 현지어 + 발음 | 필수 |
| 예측 답변 버튼 | 서버가 탭해서 답할 수 있는 버튼 세트 | 필수 |
| 즐겨찾기 | 자주 쓰는 프리셋 저장 | 권장 |

**대화 프리셋 카테고리:**

| 카테고리 | 예시 문장 |
|---|---|
| 기본 요청 | 물 주세요 / 반찬 더 주세요 / 그릇 바꿔주세요 / 포장해주세요 |
| 주문 | 추천 메뉴가 뭔가요 / 이거 매운가요 / 알러지 재료 확인 |
| 계산 | 계산서 주세요 / 카드 되나요 / 따로 계산해주세요 |
| 컴플레인 | 이물질이 있어요 / 메뉴가 다르게 나왔어요 / 덜 익은 것 같아요 |
| 인사 | 잘 먹겠습니다 / 잘 먹었습니다 / 맛있어요 |
| 기타 | 몇 명 자리 있나요 / 예약했어요 / 화장실이 어디에요 |

**지원 우선 언어:** 일본어, 중국어(간체), 태국어, 베트남어, 영어, 스페인어

**언어 자동 연동:** 메뉴 스캔에서 감지된 언어로 대화 프리셋 언어 자동 설정.

### 4.7 팁 & 문화 정보 (신규)

**목적:** 나라별 식당 에티켓 안내 + 메뉴 총액 기반 팁 계산

| 요소 | 내용 | 우선순위 |
|---|---|---|
| 국가 자동 감지 | 메뉴 언어 기반 국가 추정 | 필수 |
| 팁 정보 | 없음 / 선택적 / 통상 비율 | 필수 |
| 문화 칩 | 물 유무 / 반찬 서비스 / 계산 위치 | 필수 |
| 팁 계산기 | 메뉴 합계 × 팁 비율 + 세금 = 예상 총액 | 권장 |
| 국가 전환 | 수동으로 다른 나라로 전환 | 권장 |

**팁 유형:**

| 국가 | 팁 | 특이사항 |
|---|---|---|
| 미국 / 캐나다 | 15~20% 필수 | 안 주면 실례 |
| 영국 | 10~15% | service charge 청구서 확인 |
| 프랑스 | 5~10% | service compris 포함 여부 확인 |
| 일본 | 없음 | 팁 주면 오히려 실례 |
| 한국 | 없음 | 물·반찬 무료, 셀프 계산 |
| 태국 | 선택적 | 관광지 10% 관례 |
| 중국 | 없음 | 고급 호텔 식당 예외 |
| 베트남 | 없음~선택 | 관광지 소폭 기대 |

데이터는 로컬 JSON 번들 — API 호출 없음, 비용 0.

### 4.8 Trip Pass 페이월 (동일)

"구독" 언어 없음 — 전부 "패스" / "여행 기간" 언어 사용.
7일 패스 시각적 1순위. Skip 버튼 존재하되 작게 처리.

### 4.9 프로필 (신규 정의)

**목적:** 기존 기획에서 누락된 설정 항목 전부 한 곳으로

| 섹션 | 요소 | 우선순위 |
|---|---|---|
| 계정 | 이메일 / 로그아웃 | 필수 |
| 크레딧 & 패스 | 잔량 / 현재 패스 상태 / 구매 버튼 | 필수 |
| 언어 설정 | 출력 언어 / 메뉴 언어 변경 | 필수 |
| 알러지 프리셋 | 온/오프 토글, 즉시 반영 | 필수 |
| 구매 내역 | Trip Pass / Credits 이력 | 권장 |

### 4.10 에러 화면 (신규)

OCR 실패 시 즉각적인 대안 제시 — 막힌 느낌 없이.

| 요소 | 내용 |
|---|---|
| 에러 메시지 | "메뉴판을 인식하지 못했어요" + 원인 안내 |
| 재촬영 버튼 | 1순위 CTA |
| 텍스트 입력 폴백 | "음식 이름을 직접 입력하세요" |
| 갤러리 대안 | 다른 사진으로 시도 |

| 대화 프리셋 번역 데이터 제작 | ⏳ | 여행 회화책 기반, 수작업 필요 |
| 팁 데이터 20개국 정리 | ⏳ | 로컬 JSON, 리서치 필요 |

| A/B 테스트 시나리오 | ⏳ | Trip Pass 페이월 버전 2개 |

## 12. 입력 검증 UX (신규)

### 12.1 not_menu 에러 화면

음식 메뉴판이 아닌 이미지 입력 시 표시. 크레딧 차감 없음.

```
아이콘    카메라에 X 표시
제목      "메뉴판 이미지가 아닌 것 같아요"
설명      "음식 메뉴판 사진을 올려주세요."
버튼      다시 촬영 (1순위) / 갤러리에서 선택 / 직접 입력
```

실수인 경우가 대부분이므로 트롤 대응보다는 사용자 친화적 안내 톤 유지.

### 12.2 low_confidence 경고

특이한 형태의 메뉴판 (손글씨, 칠판 등) 인식 시 결과는 표시하되 경고 배너 추가.

```
상단 배너  "인식이 불확실한 항목이 있어요. 결과를 참고용으로 사용하세요."
개별 항목  confidence=low인 음식에 "?" 아이콘 표시
```
