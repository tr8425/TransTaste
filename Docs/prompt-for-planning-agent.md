## 1. 프로젝트 개요

TransTaste는 해외 여행자를 위한 **메뉴 번역 & 음식 정보 PWA**입니다.
메뉴 사진/텍스트/URL을 스캔하면 요리 번역, 알레르기 경고, 맛 프로필, 문화 팁을 제공합니다.

기술 스택: Next.js 14 + Tailwind CSS + Claude API (Vision+Text) + Supabase + Upstash Redis + Stripe
배포 예정: Vercel

## 2. 현재 빌드 완성도 (2026-03-28 기준)

### 구현 완료 (동작 확인됨)
- 온보딩: 언어 선택, 알레르기 14종 프리셋, 식이 제한 6종
- 메뉴 스캔: 이미지(카메라/갤러리)/텍스트/URL 입력 → Claude Vision API → SSE 스트리밍 결과
- 결과 화면: 요리 목록, 카테고리 필터, 가격 통화 포맷, 알레르기 태그, 콤보 추천
- Phase 2 상세: 요리 탭 시 맛 프로필(6축 레이더), 재료, 먹는 방법, Fun Fact (on-demand)
- 주문: 장바구니 추가/수량 조절/소계 + 팁 계산 → 서버에게 보여주기 (전체화면, Wake Lock)
- 회화집: 50+ 레스토랑 회화, 5개 언어 (일본어/중국어/태국어/베트남어/영어), 발음 + 예상 응답
- 팁 & 식문화: 20+ 국가 팁 비율, 식사 예절, 팁 계산기, no-tip 국가 안내 배너
- Travel Tools 허브: 회화집/팁가이드/주문을 묶는 허브 페이지
- 프로필: 설정 관리, Trip Pass 구매 모달, 크레딧 표시
- BottomNav 5탭: [Home, Travel, Scan(가운데 CTA), History, Profile]
- PWA: manifest.json, 테마 컬러, 홈 화면 추가 가능

### 수익 시스템 (구현됨)
- Free 7회 → Trip Pass 7일 $2.99 / 30일 $5.99 / 50크레딧 $1.99
- 스캔 시 크레딧 확인 + 차감 (클라이언트 사이드)
- 크레딧 소진 시 소프트 페이월 ("No scans remaining" → "Get More Scans")
- Phase 2 상세 + 콤보 추천은 LockedBlock으로 페이월 잠금
- Stripe checkout 연결 (키 미설정 시 로컬 폴백)
- 결제 성공/취소 배너 (6초 표시)

### SEO 기반 (구현됨)
- Root 메타데이터: 제목 템플릿, 160자 설명, Open Graph, Twitter Cards
- 페이지별 메타데이터: travel, phrases, tip-culture, results 각각 layout.tsx
- robots.txt: API/카메라/로딩 차단, AI 크롤러 기본 허용
- sitemap.xml: 6개 공개 페이지 동적 생성
- JSON-LD: WebApplication 스키마 (이름, 설명, 가격, 기능 목록)

### 캐싱
- Upstash Redis 30일 TTL, SHA256 해시 키
- 캐시 히트 시 즉시 반환 (크레딧 미차감)

### QA 현황
- 3라운드 QA 완료 (v1→v2→v3), 총 8건 버그 수정, 전건 PASS
- Mock 모드(API 키 없이) UI/UX 테스트 가능

## 4. 기존 전략 문서 핵심 요약

### 마케팅 전략 (transtaste-marketing-v1.md)
- 핵심 차별점: "컨텍스트 지속성" — ChatGPT는 매번 초기화, TransTaste는 알레르기·언어·히스토리 저장
- 포지션: "여행지 식당의 모든 순간을 해결하는 컴패니언 앱"
- SEO: "메뉴 스캔 + 알레르기 필터" 조합 검색 결과에 경쟁 앱 부재 (키워드 공백)
- GEO: FAQ Schema → AI 인용 → 무비용 유입 플라이휠
- 콘텐츠 전략: 음식별 페이지 (/foods/bulgogi), 국가별 가이드 (/guide/japan)
- 채널: Reddit r/travel, 여행 유튜버, Product Hunt, 카카오/네이버
- 수익화 검토중: Annual Credits $14.99/500회, 맥락형 CTA ("여행 며칠 남았나요?")

### 사업 리스크 감사 (transtaste-audit-v1.md)
- 핵심 지적: "만들 수 있는가"에 집중, "팔 수 있는가" 검증 없음
- TAM/SAM/SOM 계산 없음
- 핵심 가정 5개 미검증 (메뉴 장벽 크기, 알레르기 앱 수요, 서버 보여주기 실효성 등)
- LTV 낮음 ($11.98/년 최대) → CAC 감당 어려움 → GEO/바이럴로 CAC $0 구조 필요
- 법적 리스크: AI 알레르기 정보 제품 책임, GDPR 건강 데이터, 면책 조항 필수
- 캐싱 역설: 히트율↑ → 전환 압력↓ 가능
- 대응 완료: MVP 스코프 유지 결정 (Claude API가 공수 구조 변경), 실증 사례 2건 확보
- 미결: 사용자 50명 인터뷰, 법적 검토, 신뢰 형성, 오프라인 대응
