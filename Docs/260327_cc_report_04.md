# TransTaste 업데이트 리뷰 (전체 페이지)

전체 9개 페이지를 직접 확인했습니다. 이전 대비 상당한 완성도 향상이 있었고, 페이지별로 정리합니다.

---

## ✅ 완성된 페이지별 상태

### `/` 홈
잘 동작합니다. "7 scans left"로 텍스트가 개선된 것도 확인했습니다. 다만 **URL 버튼을 클릭하면 "Type Dish Names" 텍스트 입력 모달이 뜨는 버그**가 있습니다. URL 입력 전용 모달이 따로 구현되어야 하는데 Text 모달과 동일하게 연결되어 있습니다.

### `/onboarding` 온보딩
두 단계(소개 화면 → 언어/알러지 설정)가 잘 구성되어 있습니다. 언어 선택(English, 한국어, 日本語, 中文, ไทย, Tiếng Việt, Español, Français), 알러지 14종(Shellfish, Peanuts, Tree Nuts, Milk, Eggs, Fish, Soy, Wheat/Gluten, Sesame, Celery, Mustard, Lupin, Molluscs, Sulphites), 식이 선호(Vegan, Vegetarian, Halal, Kosher, No Beef, No Alcohol)까지 매우 잘 갖춰져 있습니다. "Skip for now" 옵션도 좋습니다. 피드백 하나를 드리자면, 상단 페이지 인디케이터(점 하나)만 보여 총 몇 단계인지 파악이 안 됩니다. 2/2처럼 숫자나 두 개의 점으로 표시해주면 더 좋습니다.

### `/camera` 카메라
카메라 불가 시 폴백("Camera not available → Choose from Gallery")이 깔끔하게 처리되어 있습니다. 하단에 갤러리/플래시 버튼도 있습니다.

### `/results` 결과 리스트
카테고리 필터 탭(All / Main / Soup / Noodle / Rice / Side / Drink / Dessert)과 음식 목록, 알러지 뱃지, 가격 표시 모두 잘 구현되어 있습니다. 개별 음식 클릭 시 상세 시트(재료, 알러지, 맛 프로필 레이더차트, Fun Facts 미리보기 + Paywall)도 작동합니다. **"See Combo Recommendations" 버튼은 클릭해도 반응이 없어 아직 미구현 상태**입니다.

### `/history` 스캔 히스토리
이전에 404였는데 **이제 정상 구현**됐습니다. 스캔 이력(ผัดไทย / とんこつラーメン / 佛跳墙)이 원문+영문 번역+시간 형식으로 잘 표시됩니다. 다만 아이템을 클릭했을 때 해당 결과로 이동하는지, 삭제 기능이 있는지 등의 인터랙션이 아직 없어 보입니다.

### `/profile` 프로필
크레딧(7 scans left + Get More Scans CTA), 언어 설정(I speak / Menu language Auto-detect), 알러지/식이 편집 링크, 계정(Not signed in / Sign In), 앱 버전(v0.2.0), Terms/Privacy 링크까지 잘 갖춰져 있습니다. 깔끔하고 필요한 정보가 모두 있습니다.

### `/phrases` 식당 대화 프리셋
완성도가 높습니다. 언어 탭(Japanese / Chinese / Thai / Vietnamese / English), 카테고리 탭(Basics / Ordering / Payment / Issues / Greetings / Other)이 모두 있고, 각 문구에 원문 + 로마자 + "Server might say" 예상 응답까지 포함되어 있어 실용적입니다. 즐겨찾기(별 아이콘)도 있습니다. "Show your phone to communicate" 서브타이틀도 사용 맥락을 잘 설명합니다.

### `/tip-culture` 팁 & 문화 가이드
Japan, Korea, China, Thailand, Vietnam, USA, UK, France, Spain, Italy, Germany, India, Turkey, Mexico, Australia 등 15개국이 지원되며, 각 나라별로 팁 문화(No tip / %, 등), 레스토랑 문화, 식사 에티켓, 알아두면 좋은 정보(Good to know)가 구조화되어 있습니다. 콘텐츠 퀄리티가 좋습니다.

### `/order` 주문서
빈 상태(Empty state) 화면이 잘 구현되어 있습니다("No items yet · Scan a menu to start ordering" + Open Camera 버튼). 아직 장바구니 담기 기능이 results와 연결되지 않았지만 페이지 자체는 준비되어 있습니다.

---

## 버그 / 개선 포인트 요약

**버그** — URL 버튼 클릭 시 Text 모달("Type Dish Names")이 열립니다. URL 전용 입력 모달(URL 주소창 + Fetch 버튼 형태)로 분리가 필요합니다.

**미구현** — "See Combo Recommendations" 버튼이 클릭해도 아무 반응이 없습니다. 또한 Results → Order로의 "담기" 연결, History 항목 클릭 시 해당 결과로 이동하는 기능이 아직 없습니다.

**네비게이션** — `/profile`, `/phrases`, `/tip-culture`, `/order`가 모두 BottomNav에 진입점이 없습니다. 현재 하단 탭이 Home / Camera / History 세 개뿐인데, 새로 추가된 페이지들(프로필, 문구, 문화, 주문)로의 접근 경로가 없어서 직접 URL을 입력해야만 볼 수 있습니다. 하단 탭 구성을 확장하거나, 홈 화면에 진입 카드/버튼을 추가하는 것을 권장합니다.

**온보딩 진입** — 온보딩이 완성됐는데, 앱 최초 실행 시 자동으로 `/onboarding`으로 리다이렉트 되는 로직이 있는지 확인이 필요합니다. 현재는 직접 URL 입력 없이는 온보딩을 볼 수 없는 상태입니다.

---

전반적으로 이전 대비 페이지 수가 크게 늘었고, 특히 `/phrases`와 `/tip-culture`의 콘텐츠 퀄리티가 높습니다. 지금 가장 우선적으로 처리할 것은 URL 버튼 버그 수정, BottomNav 접근성 개선, Combo Recommendations 구현 순으로 보입니다.
