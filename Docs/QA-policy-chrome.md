# TransTaste QA 방침 — Claude Chrome 전달용

> **작성일:** 2026-03-28
> **대상:** Claude Chrome (브라우저 기반 QA 수행자)
> **앱 URL:** http://localhost:3000 (개발 서버)

---

## 1. 프로젝트 개요

TransTaste는 해외 여행자를 위한 **메뉴 번역 & 음식 정보 앱**이다.
메뉴 사진/텍스트/URL을 입력하면 요리 번역, 맛 프로필, 알레르기 경고, 문화 팁을 제공한다.

**기술 스택:** Next.js 14 + Tailwind CSS + Anthropic Claude API + Supabase + Upstash Redis + Stripe

---

## 2. API 호출 제한 (중요)

### API Key를 소비하는 기능

| 기능 | 엔드포인트 | 비용 요소 |
|------|-----------|----------|
| **메뉴 이미지 분석** | `POST /api/analyze` (image) | Claude Vision 토큰 (고비용) |
| **메뉴 URL 분석** | `POST /api/analyze` (url) | Claude Vision 토큰 |
| **메뉴 텍스트 분석** | `POST /api/analyze` (text) | Claude 텍스트 토큰 (저비용) |
| **요리 상세 조회** | `POST /api/analyze/detail` | Claude 텍스트 토큰 |

### 제한 규칙

> **API Key를 소비하는 모든 기능의 총 호출 횟수는 최대 3회로 제한한다.**

- 이미지 분석: **최대 1회** (가장 비용이 높음)
- 텍스트/URL 분석: 이미지 분석과 합산하여 **총 3회 이내**
- 요리 상세 조회(Phase 2 detail): 합산하여 **총 3회 이내**
- Mock 모드(`ANTHROPIC_API_KEY` 미설정 시)는 제한 대상 아님 — 자유롭게 테스트 가능

**예시 허용 조합:**
- 이미지 분석 1회 + 요리 상세 2회 = 3회 (OK)
- 텍스트 분석 2회 + URL 분석 1회 = 3회 (OK)
- 이미지 분석 1회 + 텍스트 분석 1회 + 요리 상세 1회 = 3회 (OK)

## 5. 테스트 데이터 & 환경 설정

### Mock 모드 (API Key 없이 테스트)

`ANTHROPIC_API_KEY`를 `.env.local`에서 제거하거나 비워두면 Mock 모드로 전환된다.
- 2초 인위적 지연 후 샘플 메뉴 데이터 반환
- **UI/UX 테스트는 Mock 모드에서 우선 수행할 것**

### 실제 API 테스트용 샘플 입력

| 입력 유형 | 권장 테스트 데이터 | 기대 결과 |
|-----------|-------------------|-----------|
| 이미지 | 한국 식당 메뉴 사진 1장 | 한국어 메뉴 분석, 요리 10~40개 |
| 텍스트 | `불고기 18000\n비빔밥 12000\n된장찌개 9000` | 3개 요리 번역 + 상세 |
| URL | 메뉴 이미지가 있는 웹 URL | URL 기반 이미지 분석 |

### 브라우저 스토리지 초기화

테스트 전 클린 상태를 위해:
```
DevTools > Application > Storage > Clear site data
```

## 6. 버그 보고 형식

발견한 이슈는 다음 형식으로 보고:

```
[심각도] 페이지/기능 — 문제 요약
- 재현 경로: 홈 → 카메라 → 갤러리 선택 → ...
- 기대 동작: ...
- 실제 동작: ...
- 스크린샷: (가능하면 첨부)
- 브라우저/디바이스: Chrome 130 / iPhone 15 시뮬레이터
```

**심각도 기준:**
- **Critical:** 앱 크래시, 데이터 손실, 결제 오류
- **High:** 핵심 플로우 차단 (스캔 불가, 결과 미표시)
- **Medium:** UI 깨짐, 잘못된 번역/가격, 필터 오작동
- **Low:** 사소한 UI 이슈, 오타, 애니메이션 결함

## 7. QA 우선순위

1. **P0 (필수):** 온보딩 → 이미지 스캔 → 스트리밍 로딩 → 결과 표시 (핵심 플로우)
2. **P1 (높음):** 결과 필터링, 알레르기 태그, 주문 추가, 주문 제시
3. **P2 (보통):** 회화집, 팁 가이드, 프로필 설정, 스캔 이력
4. **P3 (낮음):** PWA, 반응형, 접근성, 결제 UI
