## 현재 검증 가설

다음 값은 확정 상품 정책이 아니라 코드 수정 없이 검증하기 위한 초기값이다.

| 항목 | 현재값 | 변경 방법 |
|---|---:|---|
| 누적 무료 실제 분석 | 3회 | `NEXT_PUBLIC_FREE_SCAN_LIMIT` |
| 3일 패스 가설 | `$1.99` | `src/lib/pricing-experiment.ts` |
| 7일 패스 가설 | `$3.99` | `src/lib/pricing-experiment.ts` |
| 30일 패스 가설 | `$9.99` | `src/lib/pricing-experiment.ts` |
| 가격 실험 ID | `trip_pass_v1` | `src/lib/pricing-experiment.ts` |

가격 또는 무료량을 변경할 때는 기존 데이터와 섞이지 않도록 가격 실험 ID도 함께 변경해야 한다.

## 검증 결과

- ESLint: 경고·오류 없음
- i18n: 한국어·영어 819개 키 동기화
- Next.js production build: 성공
- 가격 검증: 3·7·30일 카드 및 7일 추천 확인
- 가격 이벤트: `plan`, `experiment`, `days`, `price` 저장 확인
- 공개 BYOK: 프로필 입력란 0개, 브라우저 `x-api-key` 전송 코드 제거
- 촬영·갤러리 입력: 분석 전 이미지 미리보기·취소·추가·확인 지원
- 여행 퀵 문장: 국가 언어와 문장 키를 회화 카드까지 딥링크
- 장문 탐색: 프로필 고정 섹션 링크와 법률 문서 맨 위 이동 지원
- 누적 무료량: 신규 브라우저 기본 3회 확인
- 동일 입력 재시도: 실패 화면 → 재분석 → 결과 화면 복귀 확인
- Checkout: Stripe 미설정 및 기능 플래그 비활성 상태에서 `503`
- 데모 분석: 임의 `x-api-key` 헤더를 보내도 브라우저 키를 신뢰하지 않고 명시적 데모 결과 유지
