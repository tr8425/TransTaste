## 3. i18n 한국어 전환 검증 (신규)

### 3.1 설정 방법

온보딩에서 "한국어" 선택 후 저장하면 `output_language: "ko"`가 설정됩니다.
또는 DevTools에서 직접:
```
localStorage.setItem("transtaste_user_settings", JSON.stringify({
  "output_language": "ko",
  "allergen_preset": [],
  "dietary_beliefs": []
}))
```
설정 후 페이지 새로고침.

### 3.2 온보딩 한국어 확인 (`/onboarding`)

> 온보딩은 첫 방문 시만 표시. localStorage 초기화 후 접근.

**Step 1 (소개 화면):**

- [ ] 기능 2: "알레르기 확인" / "한 번 설정하면 어디서든 안심"
- [ ] 기능 3: "직원과 대화" / "현지어로 된 레스토랑 회화"
