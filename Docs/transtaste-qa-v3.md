# Transtaste — 추가 QA v3
> 작성일: 2026-04-03
> 전제: API 키 연동 완료 상태에서 진행
> 목적: v2 QA에서 미테스트·미포함 영역 집중 검증

---

## 작성 배경

QA v2 + API 연동 후 추가 QA 결과를 바탕으로 세 가지 이유로 추가 QA가 필요합니다.

1. **API 연동 후 결과 변경 반영** — 발음 가이드·스트리밍이 ✅로 바뀌었지만 기존 결과표에 ❌로 남아 있음
2. **테스트 조건 미충족으로 미테스트된 항목** — 크레딧 소진, Stripe 실결제, 에러 분기 등
3. **명세에는 있지만 QA에 포함되지 않은 영역** — Auth 플로우, 캐싱, 입력 4종 등

---

## 섹션 A. API 연동 후 결과 업데이트 (재검증)

> 이전 QA에서 "예시 데이터 기준 ❌" 였으나 API 연동 후 ✅로 바뀐 항목의 세부 동작 검증

### A-1. 발음 가이드 세부 검증

**전제:** API 연동 상태, 실제 메뉴판 스캔

**확인 포인트:**
- [ ] 결과 목록 카드에 발음 텍스트가 회색 이탤릭체로 표시되는가?
- [ ] 음식 상세 바텀시트에 🔊 아이콘 + 발음이 표시되는가?
- [ ] 하이픈 구분 형식이 올바른가? ("가라-아-게", "에-비-후-라-이")
- [ ] 발음 필드 경로가 `dishes[].translation.pronunciation`인가? (명세 `dishes[].pronunciation`와 불일치 — 어느 쪽을 표준으로 쓸지 결정 필요)
- [ ] 발음이 null인 메뉴가 있을 때 발음 영역이 표시되지 않는가?
- [ ] 영어 메뉴 스캔 시 영어 발음 표기로 전환되는가?

---

### A-2. 스트리밍 렌더링 세부 검증

**전제:** API 연동 상태, 이미지 스캔

**확인 포인트:**
- [ ] 스캔 후 `/loading-scan`에서 진행바·이모지·Fun Fact 배너가 표시되는가?
- [ ] 결과가 dish 단위로 점진적으로 렌더링되는가? (전체 완료 후 한꺼번에 표시 아님)
- [ ] 스트리밍 중 레이아웃이 깨지지 않는가? (카드 높이 고정 등)
- [ ] 스트리밍 완료 후 스켈레톤/로딩 UI가 정리되는가?
- [ ] 스트리밍 도중 뒤로가기 탭 시 스캔이 중단되고 홈으로 복귀하는가?

---

## 섹션 B. 크레딧 / 결제 집중 검증

> v2 QA에서 "크레딧 9회 남아있어 미테스트"였던 영역. 크레딧 소진 환경 준비 후 진행.

### B-1. 입력 타입별 크레딧 차감 검증

**전제 준비:** 크레딧을 2~3회 남긴 상태에서 시작

| 테스트 케이스 | 예상 차감 | 실제 차감 | 결과 |
|---|---|---|---|
| 이미지 스캔 (카메라) | 1크레딧 | | |
| 이미지 스캔 (갤러리) | 1크레딧 | | |
| URL 입력 스캔 | 1크레딧 | | |
| 텍스트 직접 입력 | 0.5크레딧 | | |
| 캐시 히트 (동일 이미지 재스캔) | 0크레딧 | | |

**확인 포인트:**
- [ ] 각 스캔 후 CreditBadge 숫자가 정책대로 감소하는가?
- [ ] 클라이언트 표시와 서버 실제 차감이 일치하는가? (새로고침 후에도 크레딧 유지)
- [ ] API 키 직접 사용 시에도 서버 사이드 검증이 동작하는가? **(출시 블로커)**

---

### B-2. 크레딧 소진 시나리오

**전제 준비:** 크레딧 1회 남긴 상태

**확인 포인트:**
- [ ] 마지막 크레딧 사용 후 CreditBadge가 "0 left"로 표시되는가?
- [ ] 크레딧 0 상태에서 스캔 시도 시 차단되는가? (서버 검증)
- [ ] 차단 시 "크레딧을 모두 사용했어요" 메시지 + 결제 CTA가 표시되는가?
- [ ] rate_limit 에러 코드(`8-3`)가 올바르게 처리되는가?
- [ ] 크레딧 0 상태에서도 무료 기능(회화 프리셋, 알러지 카드)은 사용 가능한가?

---

### B-3. Stripe 결제 실연동

**전제 준비:** Stripe 테스트 키 연동, 크레딧 0 또는 결제 필요 상태

**확인 포인트:**
- [ ] 페이월 옵션 선택 시 Stripe Checkout 페이지로 이동하는가?
- [ ] 테스트 카드(4242 4242 4242 4242, 만료 12/34, CVC 123)로 결제가 성공하는가?
- [ ] 결제 성공 후 크레딧/패스가 즉시 반영되는가?
- [ ] CreditBadge가 업데이트되는가?
- [ ] 결제 실패 카드(4000 0000 0000 0002)로 실패 처리가 되는가?
- [ ] 결제 창 닫기(취소) 시 페이월 모달로 복귀하는가?
- [ ] `/paywall` 라우트 404 수정됐는가?

**상품별 확인:**

| 상품 | 가격 | 결제 후 상태 변화 |
|---|---|---|
| 7일 Trip Pass | $2.99 | CreditBadge → "7일 패스 D-7" |
| 30일 Trip Pass | $5.99 | CreditBadge → "30일 패스 D-30" |
| Credits 50회 | $1.99 | CreditBadge → "+50" |
| Credits 150회 | $3.99 | CreditBadge → "+150" |

## 섹션 C. Auth 플로우

> 기능 명세 섹션 4에 있지만 QA에 포함되지 않았던 영역

**재현 경로:** 프로필 → 로그인/가입 → 이메일 회원가입

**확인 포인트:**
- [ ] 이메일 + 비밀번호 입력 → 가입 버튼 탭 시 Supabase Auth 계정이 생성되는가?

- [ ] 온보딩에서 설정한 알러지·언어 프리셋이 `user_settings` 테이블에 저장되는가?
- [ ] 중복 이메일 가입 시 에러 메시지가 표시되는가?
- [ ] 비밀번호 유효성 검사가 동작하는가? (최소 6자 이상 등)

---

### C-2. 로그인

**확인 포인트:**
- [ ] 이메일 + 비밀번호 로그인이 동작하는가?
- [ ] 로그인 후 이전 크레딧·패스 상태가 복원되는가?
- [ ] 로그인 후 이전에 설정한 알러지 프리셋이 불러와지는가?
- [ ] 잘못된 비밀번호 입력 시 에러 메시지가 표시되는가?
- [ ] 비로그인 상태에서 저장된 localStorage 데이터와 로그인 후 서버 데이터가 충돌하는 경우 처리가 되는가?

---

### C-3. 로그아웃

**확인 포인트:**
- [ ] 프로필 화면에 로그아웃 버튼이 추가됐는가? **(v2 QA에서 누락 발견)**
- [ ] 로그아웃 탭 시 확인 다이얼로그가 표시되는가?
- [ ] 로그아웃 후 비로그인 상태(localStorage fallback)로 전환되는가?
- [ ] 로그아웃 후 다른 계정으로 로그인이 가능한가?

---

### C-4. 비로그인 vs 로그인 상태 분기

**확인 포인트:**
- [ ] 비로그인 상태에서 스캔이 가능한가? (localhost fallback)
- [ ] 비로그인 크레딧 제한이 적용되는가?
- [ ] 비로그인 상태에서 알러지 프리셋 설정이 localStorage에 저장되는가?
- [ ] 로그인 후 localStorage 설정이 서버로 마이그레이션되는가?

## 섹션 F. OCR 에러 분기 집중 검증

> v2 QA에서 low_confidence, rate_limit이 미테스트였던 영역

### F-1. low_confidence 에러

**재현 방법:** 매우 흐리거나 측면에서 찍은 이미지, 또는 글자가 극히 작은 이미지 스캔

**확인 포인트:**
- [ ] "이미지가 흐릿해요" 또는 유사한 메시지가 표시되는가?
- [ ] 0.5크레딧만 차감되는가? (1크레딧 아님)
- [ ] 재촬영 권유 + 텍스트 직접 입력 대안이 제공되는가?
- [ ] not_menu 에러와 메시지가 구분되는가?

---

### F-2. 에러 메시지 한국어 통일

> v2 QA에서 "No image or text provided. Please try again." 영어 하드코딩 발견

**확인 포인트:**
- [ ] 모든 에러 메시지가 `output_language` 설정을 따르는가?
- [ ] 영어로 설정 시 영어, 한국어 설정 시 한국어로 표시되는가?
- [ ] `/loading-scan` 에러 화면의 영어 메시지가 수정됐는가?

---

### F-3. 에러 화면 UX

**확인 포인트:**
- [ ] 에러 화면에서 재시도 버튼이 동작하는가?
- [ ] 에러 화면에서 텍스트 직접 입력 대안으로 이동 가능한가?
- [ ] 에러 화면 배경이 친근한 톤인가? (냉랭한 흰 화면 아님)
- [ ] 에러 화면에서 홈으로 돌아가기가 가능한가?

### 우선순위별 수정 권장 사항

**🔴 P0 — 출시 블로커**
1. **G — 다국어 미적용** — fun_fact, ingredients, how_to_eat, 레이더 라벨 모두 영어 고정. `output_language: ko` 설정이 AI 프롬프트에 제대로 전달되지 않는 것으로 추정
2. **C — Auth 전체 미구현** — /login·/signup 404, 로그인 버튼 onClick 없음. Supabase Auth UI 연결 필요
3. **H — 스캔 단위 오류** — 홈 최근 스캔 칩 + 히스토리 모두 요리 단위. 스캔 1건 = 카드/칩 1개로 묶어야 함

**🟠 P1 — 출시 전 필수**
4. **NEW-1 — "undefined회" 버그** — API 키 있을 때 크레딧 배지 렌더링 오류. `Infinity` 숫자 처리 필요
5. **B-1 — 크레딧 차감 미동작** — API 키 우회 시에도 정상 차감 또는 "무제한" 명시 UI 필요
6. **F-2 — 에러 메시지 혼용** — API 서버 에러 메시지를 한국어로 변환 후 표시 필요
7. **NEW-2 — URL 유효성 검사 없음** — `https://`로 시작하는지, 이미지 확장자인지 최소 검증 필요

**🟡 P2 — 빠른 개선**
8. **NEW-3 — 모달 모바일 잘림** — 텍스트/URL 모달이 낮은 뷰포트에서 버튼 노출 안 됨. `max-height + overflow-y: auto` 처리 권장
9. **A-1 — 영어 메뉴 발음** — 영어 원어 메뉴에 한국어 음성전사 대신 IPA 또는 영어 발음 가이드 표시 고려
10. **B-3 — Stripe 미연결** — 결제 옵션 클릭 시 Stripe Checkout으로 연결 필요
