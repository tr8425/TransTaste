## 1. POC 스크립트 검증

**User**: `@README.md @test-menu.mjs` 읽고 검증해봐

**Claude**: 두 파일을 읽고 검증한 결과:

- `package.json`이 없음 — `npm install` 실행 불가

즉시 해야 할 것: `npm init -y && npm install @anthropic-ai/sdk`

## 3. 프론트엔드 UI 구축 시작

**User**: `@Docs\transtaste-frontend-report.md @Docs\transtaste-backend-report.md` 확인해서 계획 작성해줘. 필요하다면 이 작업을 위한 SubAgent, Skills 작성도 해줘

**Claude**: 플랜 모드 진입 → 리포트 분석 → Plan 에이전트로 구체적 구현 계획 설계 → 최종 플랜 파일 작성

**6 Phase 구조:**
- Phase 0: 프로젝트 세팅 (POC 이동 + Next.js 초기화)
- Phase 1: 기반 코드 (types, constants, mock-data, tailwind, layout)
- Phase 2: 원자 컴포넌트 (7개 병렬 — AllergyTag, IngredientChip, LockedBlock, CreditBadge, FunFactCard, Button, Badge)
- Phase 3: 복합 컴포넌트 (FlavorRadar, DishRow, DishCard, BottomSheet, CameraView, LoadingScreen 등)
- Phase 4: 화면 조립 (홈, 카메라, 로딩, 결과, 페이월)
- Phase 5: PWA + 마무리

실제 API/DB/결제 연동 없이 **목업 데이터 기반 UI 셸**만 구축. Phase 2~3에서 SubAgent 병렬 실행으로 속도 향상.

## 4. 플랜 승인 → 구현

**User**: (플랜 승인)

**Claude**: 전체 구현 진행

### Phase 0 — 프로젝트 세팅
- 기존 POC 파일을 `poc/`로 이동
- Next.js 14 초기화 (디렉토리명 대문자 이슈로 임시 디렉토리에서 생성 후 복사)
- 빌드 성공 확인

### Phase 1 — 기반 코드
- `src/lib/types.ts` — Dish, FlavorProfile, Translation 등 전체 인터페이스
- `src/lib/constants.ts` — 브랜드 컬러, 알러지 색상맵, 맛 축, 패스 옵션
- `src/lib/mock-data.ts` — 한국어 메뉴 5개 목업 (불도장, 삼겹살, 된장찌개, 비빔냉면, 막걸리)
- `tailwind.config.ts` — coral, cream, brown 등 커스텀 컬러
- `src/app/globals.css` — Google Fonts + base body 스타일
- `src/app/layout.tsx` — 모바일 컨테이너, PWA meta

### Phase 2 — 원자 컴포넌트 (SubAgent 3개 병렬)
- Agent A: AllergyTag, IngredientChip, LockedBlock
- Agent B: CreditBadge, FunFactCard
- Agent C: Button, Badge

### Phase 3 — 복합 컴포넌트
- FlavorRadar (순수 SVG 6축 레이더)
- BottomSheet (슬라이드업 85vh)
- DishRow, DishCard
- CameraView + useCamera 훅
- LoadingScreen
- RecentHistory, TripPassPaywall, ComboRecommendation
- useCredits 훅

### Phase 4 — 화면 조립
- `/` — 홈 (카메라 CTA, 크레딧 뱃지, 최근 스캔)
- `/camera` — 카메라 뷰파인더
- `/loading-scan` — 로딩 애니메이션 + Fun Fact (3초 후 results 이동)
- `/results` — DishRow 리스트 + 필터 + DishCard 상세 + 조합 추천 + 페이월

### Phase 5 — PWA + 마무리
- `public/manifest.json`
- `src/app/api/analyze/route.ts` — 목업 API (2초 딜레이)
- README.md 재작성

**결과**: 27개 파일 생성, 빌드 성공

## 7. 개선 구현

**User**: 우선순위대로 진행해줘

**Claude**: P0 → P1 → P2 순서로 전체 구현 완료

### P0 — LockedBlock CTA 중복 제거
- LockedBlock에서 내부 CTA 제거 (blur + 잠금 아이콘만 유지)
- DishCard에서 FlavorRadar/FunFact/HowToEat를 하나의 blur 그룹으로 통합
- 그룹 아래에 단일 CTA: "Unlock flavors, facts & more — $2.99" + "7-Day Trip Pass · One-time payment" 설명

### P0 — 카테고리 탭 잘림 수정
- `whitespace-nowrap` 추가로 텍스트 잘림 방지
- 우측 `gradient-to-l from-cream` fade 오버레이로 스크롤 가능 암시

### P0 — 크레딧 뱃지 명확화
- 원형 아이콘 → 번개(bolt) 아이콘으로 변경
- "7" → "7 left" 레이블 추가
- Pass 상태도 "Pass" → "Trip Pass" 명시

### P1 — 바텀 네비게이션
- `BottomNav` 컴포넌트 신규: Home / Scan(중앙 FAB) / History 3탭
- 카메라(`/camera`)와 로딩(`/loading-scan`)에서 자동 숨김
- layout.tsx에 통합
- results 페이지 하단 Combo 버튼 위치를 BottomNav 위로 조정

### P1 — 홈 화면 레이아웃 재구성
- `justify-center` 제거 → 상단 정렬
- 히어로 280px → 160px로 축소
- "Popular Dishes Nearby" 2x2 그리드 섹션 추가 (Pho Bo, Omakase, Tom Yum, Xiao Long Bao)
- Recent Scans를 CTA 바로 아래 배치

### P1 — 카메라 에러 상태 개선
- 검정 화면 + 텍스트 → 친근한 UI로 교체
- 📷 이모지 + "Camera not available" 제목
- 주요 CTA: "Choose from Gallery" (coral, 풀 너비)
- 보조: "Try camera again" (텍스트 링크)

### P2 — Recent Scans 네비게이션 연결
- `<button>` → `<Link href="/results">` 변경
