**TransTaste 앱 모바일 UIUX 소감**

---

## 앱 개요

TransTaste는 해외 레스토랑에서 외국어 메뉴판을 카메라로 찍으면 번역 + 알레르기 정보 + 맛 프로필을 보여주는 앱입니다. 구현된 화면은 홈(`/`), 카메라(`/camera`), 메뉴 결과(`/results`) 세 개입니다.

---

## 잘 된 점 👍

**비주얼 & 브랜딩**
- 따뜻한 베이지/크림 계열의 배경색과 주황-갈색 액센트 컬러가 일관되게 적용되어 있고, 음식 앱에 어울리는 포근한 분위기를 만들어냅니다.
- "Trans**Taste**"에서 Taste만 주황색으로 강조한 로고 타이포그래피가 깔끔합니다.
- 각 메뉴 아이템에 이모지/일러스트 아이콘을 사용해 시각적으로 인식하기 쉽습니다.

**홈 화면**
- 메인 액션(카메라 촬영)이 화면 중앙에 큼직한 원형 FAB 버튼으로 배치되어 있어 첫 진입 사용자도 무엇을 해야 하는지 직관적으로 알 수 있습니다.
- "Recent Scans" 섹션으로 히스토리를 빠르게 재접근할 수 있는 동선이 좋습니다.

**메뉴 결과 화면**
- All / Main / Soup / Noodle / Rice / Side / Drink / Dessert 카테고리 필터 탭이 있어 많은 메뉴가 있을 때 탐색이 편리합니다. 필터 전환도 즉각 반응합니다.
- 각 메뉴 카드에 한국어 원문 + 영어 번역 + 알레르기 태그(Shellfish, Pork, Gluten 등)를 한 번에 보여주는 정보 구조가 효율적입니다.
- 가격이 주황색으로 강조되어 시선이 잘 가며, 아이콘-텍스트-태그의 계층이 명확합니다.

**상세 모달**
- 하단에서 올라오는 Bottom Sheet 형식으로 컨텍스트를 유지하면서 상세 정보를 보여주는 방식이 모바일 패턴에 잘 맞습니다.
- 재료(INGREDIENTS), 알레르기(ALLERGENS & DIETARY), 맛 프로파일(FLAVOR PROFILE) 섹션 구분이 명확합니다.

---

## 개선이 필요한 점 ⚠️

**홈 화면 공백 과다**
- 이미지 카드와 버튼 영역 사이, 버튼과 Recent Scans 사이에 빈 공간이 지나치게 많습니다. 화면의 약 40%가 비어 있어 모바일에서 불필요하게 스크롤해야 하는 느낌을 줍니다. "Recent Scans" 섹션을 위로 올리거나, 자주 쓴 메뉴 / 추천 기능을 배치해 공간을 채우면 좋겠습니다.

**카테고리 탭 텍스트 잘림**
- "Drink"가 "Drin"으로 잘려 보입니다. 모바일 폭에서 탭이 모두 들어가지 않으면 좌우 스크롤 가능 탭으로 구성하거나, 텍스트를 아이콘+약어로 처리하는 것이 필요합니다.

**Recent Scans 버튼 미작동**
- 홈 화면의 최근 스캔 항목(ผัดไทย 등)을 클릭해도 해당 결과 페이지로 이동하지 않습니다. 버튼 요소로 구현되어 있으나 실제 네비게이션이 연결되지 않은 상태입니다.

**"Unlock with Trip Pass" 페이월 UX**
- Flavor Profile, 콤보 추천 등 핵심 콘텐츠 상당 부분이 잠겨 있고 같은 화면에 "Unlock with Trip Pass" 링크가 3~4회 반복 노출됩니다. 잠긴 이유나 Trip Pass가 무엇인지 설명이 없어 첫 사용자에게 답답한 경험을 줍니다. 잠금 처리는 유지하되, 한 번만 명확한 업그레이드 CTA로 정리하는 것을 추천합니다.

**바텀 네비게이션 부재**
- 현재 화면 간 이동이 Back 버튼과 URL 직접 입력으로만 가능합니다. 모바일 앱답게 홈/스캔/히스토리/프로필 등을 아우르는 바텀 탭 바가 있으면 탐색성이 크게 올라갑니다.

**카메라 오류 처리**
- 카메라가 없을 때 "Requested device not found" 텍스트만 검정 화면에 표시되어 매우 냉랭한 인상입니다. 친근한 일러스트와 "갤러리에서 이미지 선택" 대안 액션을 함께 보여주면 오류 상황에서도 사용자 이탈을 줄일 수 있습니다.

**우측 상단 🔔 7 아이콘 미작동**
- 알림 아이콘처럼 보이지만 클릭해도 반응이 없습니다. 인터랙션이 없다면 아직 미구현 상태인 것 같은데, 목업 단계라도 드로어나 빈 상태 화면으로 연결해두면 완성도가 올라갑니다.

---

## 종합 평가

앱의 핵심 가치(외국어 메뉴 스캔 → 번역 + 알레르기 정보)는 명확하게 전달되고, 비주얼 디자인 퀄리티도 준수합니다. 다만 현재 mockup은 홈→결과→상세 모달의 주요 플로우 외에 네비게이션이 거의 없어 전체 UX 구조를 평가하기 어렵습니다. 바텀 탭 바 추가, 홈 화면 공백 정리, 카테고리 탭 텍스트 잘림 수정, Recent Scans 인터랙션 연결을 우선적으로 보완하면 완성도가 크게 높아질 것 같습니다.
