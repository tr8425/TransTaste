## Claude Chrome에게 — 테스트 지침

이 문서는 Transtaste v2 신규 기능 및 기존 v1 버그 수정 사항을 검증하기 위한 QA 체크리스트입니다.
각 항목을 직접 실행하고, **결과를 ✅ 통과 / ❌ 실패 / ⚠️ 부분 동작** 으로 기록해주세요.
실패 항목은 구체적인 재현 경로와 실제 동작 vs 예상 동작을 함께 기술해주세요.

테스트 순서: **섹션 1(기존 버그 검증) → 섹션 2~9(신규 기능) → 섹션 10(회귀 테스트)**

## 섹션 1. 기존 v1 버그 — 수정 검증

> 이전 QA에서 발견된 버그들이 실제로 수정됐는지 확인

### 1-1. 히스토리 URL 고유화 🔴 (기존 심각)

**재현 경로:**
1. 홈 화면 접속
2. Recent Scans 칩 3개 확인
3. 각 칩 클릭

**예상 동작:**
- 각 칩 클릭 시 서로 다른 URL(`/results?id=xxx`)로 이동
- 클릭한 음식의 스캔 결과가 표시됨

**확인 포인트:**
- [ ] 칩 3개가 각각 다른 id 파라미터를 가지는가?
- [ ] 잘못된 id 입력 시 에러 처리가 되는가?

---

### 1-2. 카메라 뒤로가기 버튼 🔴 (기존 심각)

**재현 경로:**
1. 홈 화면 → 카메라 FAB 탭
2. /camera 진입 확인

**예상 동작:**
- 좌상단에 X 또는 ← 버튼 존재
- BottomNav 숨김 상태 (카메라 화면에서 정상)
- X 탭 시 이전 화면(홈)으로 복귀

**확인 포인트:**
- [ ] 뒤로가기 버튼 존재하는가?
- [ ] 탭 시 홈으로 정상 복귀하는가?
- [ ] 브라우저 뒤로가기와 동일하게 동작하는가?

---

### 1-3. Popular Dishes 클릭 인터랙션 🔴 (기존 심각)

**재현 경로:**
1. 홈 화면 → Popular Dishes 섹션
2. 카드 탭

**예상 동작 (옵션 A):** 해당 음식 상세 검색 화면으로 이동
**예상 동작 (옵션 B):** 인터랙션 없음 + 시각적으로 클릭 불가로 표시

**확인 포인트:**
- [ ] 시각적 hover/active 상태가 있는가?
- [ ] 클릭 시 예상 동작이 실행되는가?
- [ ] "클릭 가능해 보이지만 아무 반응 없음" 상태는 아닌가?

---

### 1-4. user-scalable=no 제거 🟠 (기존 중요)

**확인 방법:** 뷰포트 메타 태그 확인

**예상 동작:**
```html
<!-- 수정 전 (잘못된 상태) -->
<meta name="viewport" content="..., user-scalable=no, maximum-scale=1">

<!-- 수정 후 (올바른 상태) -->
<meta name="viewport" content="width=device-width, initial-scale=1">
```

**확인 포인트:**
- [ ] `user-scalable=no` 제거됐는가?
- [ ] `maximum-scale=1` 제거됐는가?
- [ ] 화면 핀치 줌이 동작하는가?

---

### 1-5. 온보딩 Skip for now 버튼 가려짐 🟠 (기존 중요)

**재현 경로:**
1. /onboarding 직접 접속
2. 슬라이드 2 (알러지 설정 화면)

**예상 동작:**
- "Skip for now" 버튼이 BottomNav 위에 완전히 보임
- 탭 시 홈으로 이동

**확인 포인트:**
- [ ] Skip 버튼이 BottomNav에 가려지지 않는가?
- [ ] z-index 처리가 올바른가?
- [ ] 탭 시 홈(/home)으로 이동하는가?

---

### 1-6. OG 이미지 / 메타 태그 🟡 (기존 개선 사항)

**확인 방법:** 페이지 소스 또는 DevTools

**확인 포인트:**
- [ ] `og:image` 태그 존재하는가?
- [ ] 주요 페이지별로 다른 `<title>` 태그를 가지는가?
  - 홈: "Transtaste — 여행 메뉴판 번역"
  - 결과: "스캔 결과 — Transtaste"
  - 프로필: "프로필 — Transtaste"

---

### 1-7. robots.txt noindex 🔴 (런칭 블로커)

**확인 방법:** `/robots.txt` 직접 접속

**예상 동작:**
```
# 수정 전 (잘못된 상태)
User-agent: *
Disallow: /
noindex: /

# 수정 후 (올바른 상태)
User-agent: *
Allow: /
Disallow: /api/
Disallow: /admin/
```

**확인 포인트:**
- [ ] noindex, nofollow 제거됐는가?
- [ ] 공개 페이지는 크롤링 허용됐는가?
