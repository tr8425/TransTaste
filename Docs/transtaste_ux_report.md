# Transtaste UX 감사 리포트

> **작성일:** 2026-04-01  
> **버전 기준:** v0.2.0 (로컬 빌드)  
> **검토 방법:** Claude in Chrome 직접 접근 (localhost:3000)  
> **검토 범위:** 전체 화면 UX, 기능 동작, 마케팅 문서(v0.2) 대비 실제 구현 상태

---

## 요약

현재 빌드는 **UI 골격 완성 + 핵심 파이프라인 작동** 상태다. 텍스트 입력 → AI 분석 → 결과 표시까지 엔드투엔드가 작동하며, 알러지 경고 기능이 실제로 정확하게 동작하는 것을 확인했다. 이미지 스캔 파이프라인은 직접 테스트하지 않았으나 동일 구조로 작동할 것으로 판단된다.

런칭 전 반드시 수정해야 할 **블로커 2개**, 즉시 수정 가능한 **버그 1개**, 출시 후 개선 권장 항목들이 있다.

| 슬라이드 | 내용 | 평가 |

| 2 | 기능 3줄 소개 + "무료 스캔 10회 포함" 뱃지 | ✅ 깔끔 |

**개선 권장:** 슬라이드 3을 언어 → 알러지 → 여행지 3단계로 분리하면 완료율 향상 예상.

### 1.3 스캔 결과 (`/results`)

**핵심 파이프라인 정상 작동 확인.** 텍스트 입력(唐揚げ, 海老フライ, 麻婆豆腐)으로 직접 테스트.

| 항목 | 상태 | 비고 |
|------|------|------|
| 메뉴 리스트 (한/영 번역) | ✅ 작동 | 唐揚げ → 가라아게, 海老フライ → 에비후라이 |
| 알러지 배지 (무료) | ✅ 작동 | 海老フライ에 갑각류·글루텐·달걀 정확히 표시 |
| 알러지 경고 배너 | ✅ 작동 | "알레르기 성분이 포함되어 있습니다. 다른 요리를 고려해보세요." |
| 카테고리 탭 필터 | ✅ 표시 | 전체/메인/국·찌개/면/밥/반찬/음료/디저트 |

## 2. 블로커 — 런칭 전 반드시 수정

### 🔴 BLOCKER 1: `robots: noindex, nofollow` 설정됨

**현황:** 메타태그에 `noindex, nofollow`가 설정되어 있어 Google, GPTBot, ClaudeBot, PerplexityBot 모두 크롤링 불가.

**영향:** 마케팅 문서(v0.2)에서 가장 공을 들인 SEO/GEO 전략 전체가 무력화된다. 음식 페이지 50개, FAQ Schema 마크업, llms.txt 등 모든 콘텐츠 전략의 효과가 0이 된다.

**수정 방법:**
```html
<!-- 제거 -->
<meta name="robots" content="noindex, nofollow">

<!-- robots.txt에 추가 -->
User-agent: GPTBot
Allow: /

User-agent: ClaudeBot
Allow: /

User-agent: PerplexityBot
Allow: /
```

**커스텀 도메인(transtaste.app) 이전 시 동시 처리 필수.**

---

### 🔴 BLOCKER 2: 마케팅 메시지 vs 실제 구현 불일치

**현황:** 앱스토어 설명 및 온보딩에서 "알러지 확인" 기능을 전면에 내세우고 있으나, vercel 빌드 기준 알러지 정보 전체가 유료 페이월 뒤에 잠겨 있었음.

**현재 로컬 빌드:** 알러지 위험 배지(❌ 갑각류·글루텐·달걀)는 무료 노출, 상세 정보는 유료. → **옵션 B 구현 확인됨.**

**확인 필요:** 이 상태가 vercel 배포 버전에도 반영되었는지 확인 후 배포. 배포 버전과 로컬 버전의 알러지 노출 정책이 일치해야 한다.

## 3. 즉시 수정 권장 버그

### 🟠 i18n 키 노출 — 페이월 모달 크레딧 옵션

**현황:** 페이월 모달에서 세 번째 결제 옵션(Credits $1.99)의 제목과 설명이 번역 키 그대로 노출됨.

```
paywall.passcredits50
paywall.passcredits50Desc
```

**영향:** 결제 직전 화면에서 미완성 인상을 주어 신뢰도 저하, 전환율 감소 가능성.

**수정:** i18n 파일에 해당 키 번역 추가 (5분 내 수정 가능).

```json
{
  "paywall": {
    "passcredits50": "50회 크레딧",
    "passcredits50Desc": "필요할 때만 충전, 원하는 만큼"
  }
}
```

## 5. 핵심 기능 동작 확인 (텍스트 입력 테스트)

**테스트 입력:** 唐揚げ / 海老フライ / 麻婆豆腐 (일본어 메뉴)

**결과:**

| 메뉴 | 번역 | 알러지 배지 | 경고 배너 |
|------|------|------------|---------|
| 唐揚げ | 가라아게 (일본식 치킨 튀김) | 직원 문의 / 글루텐 | - |
| 海老フライ | 에비후라이 (새우 튀김) | **갑각류** / 글루텐 / 달걀 | ✅ "알레르기 성분이 포함되어 있습니다" |
| 麻婆豆腐 | 마파두부 (매운 두부 볶음) | **돼지고기** / 대두 | ✅ 경고 배너 |

**중요 확인 사항:**
- 프로필에 저장된 알러지 프리셋(갑각류·달걀)이 결과 화면에 **정확히 반영**됨
- 알러지 배지는 **무료로 노출** — 마케팅 메시지와 일치
- API 연결 및 AI 분석 완전 작동 확인
