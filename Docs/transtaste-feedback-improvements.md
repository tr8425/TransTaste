## 1. 카메라 화면 — 스캔 중 시각적 피드백 없음

**피드백 원문:**
> "현재는 검은 화면에 가이드 텍스트만 있는데, 메뉴를 인식하는 중임을 알려주는 시각적 피드백(스캔 애니메이션, 테두리 인식 등)이 있으면 사용 경험이 좋아집니다."

**현재 상태:**
- 카메라 화면: 검은 배경 + 정적 가이드 텍스트
- 촬영 후 → 로딩 화면으로 전환 (스캔 중 피드백 없음)

**개선 방향:**

```
옵션 A — 촬영 후 피드백
  셔터 탭 → 화면 순간 flash 효과
  → "분석 중..." 텍스트 + 스피너
  → 로딩 화면으로 전환
  난이도: 낮음 (CSS animation)

옵션 B — 실시간 스캔 가이드
  뷰파인더 안에 모서리 브라켓 표시 (📷 프레임 가이드)
  텍스트 감지 시 브라켓 색상 변경 (회색 → 코랄)
  "메뉴판을 프레임 안에 맞춰주세요" 안내
  난이도: 중간

옵션 C — 촬영 성공 확인
  촬영 후 썸네일 미리보기 + "이 이미지로 분석할까요?"
  재촬영 / 확인 버튼
  난이도: 낮음, 사용자 실수 방지 효과 큼
```

**권장:** 옵션 A + C 조합. 즉각 구현 가능하고 임팩트가 큽니다.

**구현 상태:** 완료 — 촬영 flash·프레임 가이드와 촬영/갤러리 이미지 미리보기 후 분석 확인 흐름 반영.

## 2. 홈 통화 설정 — 발견하기 어렵고 설정 흐름 불분명

**피드백 원문:**
> "프로필에 '홈 통화 — 설정 안 됨'이라고 나오는데, 가격 환산 기능은 여행자에게 꽤 유용한 기능임에도 눈에 잘 안 띄고 설정하기 어렵습니다."

**현재 상태:**
- 프로필 화면에 "홈 통화 — 설정 안 됨" 텍스트만 표시
- 탭해도 어떻게 설정하는지 불분명
- 환율 토글 자체는 v2+ 기능이지만 설정 진입은 v2에 포함

**개선 방향:**

```
1. 온보딩 2단계에 홈 통화 선택 추가
   언어 선택 바로 아래
   "내 기준 통화: KRW ▼" (드롭다운)
   → 여행자가 앱 시작 시 자연스럽게 설정

2. 프로필 홈 통화 셀 → 탭 시 바텀시트로 선택 UI 제공
   현재: 탭 → 아무 반응 없음 (추정)
   개선: 탭 → 통화 선택 바텀시트
   옵션: KRW, JPY, USD, CNY, THB, VND (6종)

3. 설정 전까지 가격 표시 방식 명확화
   현재: "설정 안 됨" — 왜 설정해야 하는지 모름
   개선: "가격을 내 통화로 보려면 탭하세요 →"
          (기능 이점을 먼저 설명)
```

**구현 상태:** 완료 — 온보딩과 프로필에서 홈 통화를 직접 선택하며 결과 화면 환산에 연결.

## 3. 여행 탭 빠른 실행 버튼 → 회화 페이지 딥링크 없음

**피드백 원문:**
> "여행 페이지 상단의 빠른 실행 버튼('물 주세요', '계산서 주세요' 등)은 정말 좋은 아이디어인데, 회화 페이지에서 해당 언어로 바로 연결되면 더 좋을 것 같습니다."

**현재 상태:**
- /travel 상단: 빠른 실행 버튼 ("물 주세요", "계산서 주세요" 등)
- 탭 시: /phrases 전체 페이지로 이동 (특정 프리셋 미연결)

**개선 방향:**

```
빠른 실행 버튼 탭 시:
  현재 → /phrases (처음부터 탐색 필요)
  개선 → /phrases?key=water_please&lang=ja (해당 항목으로 스크롤 + 하이라이트)

구현 방식:
  URL 파라미터로 프리셋 key 전달
  /phrases 진입 시 key 파라미터 감지 → 해당 항목 자동 포커스
  현지어 발음 즉시 재생 (선택적)
```

**예상 효과:** 클릭 → 원하는 회화 카드까지 2탭에서 1탭으로 단축

**구현 상태:** 완료 — `key`·`lang` 파라미터로 해당 카드에 스크롤·포커스·하이라이트.

## 4. 스캔 결과 카테고리 탭 — 스크롤 시 사라짐

**피드백 원문:**
> "메뉴 결과 화면의 카테고리 탭 필터(메인/국찌개/면 등)는 실제로 써보면 꽤 유용한 기능인데 시각적으로 묻혀있어서, 스크롤 시 상단에 고정(sticky)되면 훨씬 발견하기 쉬울 것 같습니다."

**현재 상태:**
- /results 화면: 카테고리 탭이 목록 상단에 위치
- 스크롤 시 탭이 화면 밖으로 사라짐
- 다른 카테고리로 전환하려면 위로 다시 스크롤해야 함

**개선 방향:**

```css
/* 카테고리 탭 sticky 처리 */
.category-tab-bar {
  position: sticky;
  top: 0;               /* 또는 헤더 높이(56px) */
  z-index: 10;
  background: var(--bg-cream);
  padding: 8px 0;
  border-bottom: 1px solid var(--border-light);
}
```

**주의:**
- 헤더(로고 + CreditBadge)와 겹치지 않도록 top 값 조정 필요
- BottomNav와 sticky 탭 사이 콘텐츠 영역 높이 계산
- 탭이 sticky 상태임을 알 수 있는 미세한 그림자 추가 권장

**난이도:** 낮음 (CSS 수정 + 높이 조정)

**구현 상태:** 완료 — 결과 카테고리 바 sticky 처리와 가로 스크롤 힌트 반영.
