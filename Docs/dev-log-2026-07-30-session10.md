# TransTaste 개발 로그

> 2026-07-30 세션 10 — 제품성 검토, 디자인·플로우 개선, 로컬 전수 QA

## 세션 요약

Supabase와 Stripe에 아직 투자하지 않는 현재 조건을 전제로 제품의 상업성, 접근성, 비주얼, 핵심 사용자 흐름을 재검토했다. 결제나 데이터베이스 없이도 구축 가능성과 구매 의향을 검증할 수 있도록 데모 경계와 가격 실험을 정비했으며, 제품 방침이 필요 없는 UI/UX 이슈는 코드에 바로 반영했다.

프로덕션 배포는 하지 않았다. 현재 빌드는 로컬 데모와 검증용이며, 실 AI·계정·결제 품질이 확인되기 전 `transtaste.vercel.app`에 올리지 않는 방침을 유지한다.

## 주요 변경

### 제품 검토와 의사결정 문서

- 상품성·시장성·사용자 접근성·비주얼 평가 작성
- Codex 기반 디자인 및 사용자 흐름 개선 계획 작성
- 3일·7일·30일 패스 구조와 7일 추천안 반영
- 무료 사용량은 누적 3회 기본값으로 구성하고 환경변수로 조정 가능하게 처리
- 가격은 확정값이 아니라 검증 가설임을 UI와 문서에 명시
- 사용자 검증 프로토콜과 기록용 scorecard 추가

### 데모와 프로덕션 안전 경계

- `ENABLE_DEMO_ANALYSIS=true`일 때만 고정 데모 분석 허용
- API 키와 데모 플래그가 없으면 구조화된 `503` 오류 반환
- 상세 분석 API도 동일한 데모 경계를 따르도록 정렬
- 브라우저 BYOK 입력과 `x-api-key` 전달 제거
- Stripe 미설정 시 성공 처리·로컬 권한 부여하던 우회 제거
- 결제 성공 쿼리만으로 패스·크레딧·상세 권한을 부여하지 않도록 차단
- `.env.example`에 실서비스·로컬 QA 변수와 주의사항 정리

### 핵심 사용자 흐름

- 홈 가치 제안과 CTA 계층 정리
- 스캔 전 알레르기·식이 제한을 확인하는 `/scan-setup` 추가
- 업로드 → 메뉴 읽기 → 요리 파악 → 안전 확인 단계형 로딩 제공
- 실패 시 마지막 분석 재시도와 텍스트 입력 복구 경로 제공
- 결과의 위험도·대안·주문 CTA와 sticky 카테고리 탐색 개선
- 주문 화면과 직원 제시 모드의 언어·가격·주의사항 전달 보완
- `/pricing`에서 3일·7일·30일 관심 이벤트를 로컬 기록

### 접근성·UI/UX 후속 개선

- 카메라 아이콘 버튼에 접근 가능한 이름·상태·포커스 처리
- 촬영·갤러리 선택 후 이미지 미리보기와 분석 전 확인 단계 추가
- 가로 스크롤 목록 양끝 힌트 추가
- 가격 선택 버튼에 `aria-pressed` 추가
- 로딩에 `aria-live`, `aria-busy`, progressbar 의미 구조 추가
- 여행 퀵 문장을 언어·문장 카드로 딥링크하고 대상 카드 포커스·하이라이트
- 프로필에 고정 섹션 바로가기 추가
- 개인정보처리방침·이용약관에 맨 위 복귀 동선 추가

### 프로젝트 연결

- 이 Next.js 레포에서만 user-scope `unityMCP`를 비활성화하는 `.codex/config.toml` 추가
- 다른 Unity 프로젝트의 공용 MCP 등록은 변경하지 않음
- Vercel 프로젝트 연결 상태는 유지했지만 배포는 실행하지 않음
